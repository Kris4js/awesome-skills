# Deploy DSH Superagent

从自托管服务器上的实际部署过程整理，覆盖 DeepSeek Harness、飞书机器人、GitHub/GitLab 代码仓库和任务验收。

## 内容与使用范围

| 入口 | 用途 |
| --- | --- |
| [SKILL.md](SKILL.md) | 任务范围、部署顺序与非显然的操作约束 |
| [运行环境](references/runtime.md) | 版本兼容、普通服务账号、systemd、模型配置与工具测试 |
| [飞书](references/feishu.md) | 机器人权限、长连接、接单群与消息验证 |

| [配置与验收](references/acceptance.md) | 准入、并发、管理 API、只读任务与代码任务的不同证据 |

三个 Python 辅助脚本分别生成无密钥配置、隐藏输入平台凭据和测试模型。GitLab 补丁有固定基线与适用范围，不能对任意新版原型直接套用。

## 前置条件

- 本地生成器与离线检查：Python 3.9+。模型探测还需要支持 `--env-file` 的 Node.js。
- 实际部署：用户授权的 Linux/SSH 环境、DSH、符合目标仓库要求的 Node.js/pnpm、代码平台 CLI、飞书应用与模型服务。
- Rex 只是复用既有 SSH 终端的一种方式，不是部署的强制依赖。
- 创建凭据和开通平台权限由有权用户完成；脚本不能替代授权。
