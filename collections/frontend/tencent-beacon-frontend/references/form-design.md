# 表单填写界面引用规范

适用于数据连接、资源配置等工作台内的紧凑填写页面。以已校准的 MySQL 表单为视觉基准；复用时替换业务字段、校验和服务接口，保留排版与控件层级。此规范定义设计约束，组件实现使用 [BeaconConnectionForm.tsx](../templates/BeaconConnectionForm.tsx) 与 [beacon.css](../templates/beacon.css)。

![表单填写界面](../gallery/connection-preview.png)

## 如何引用

在设计或开发任务中引用以下指令，并补充字段定义：

> 按 `references/form-design.md` 构建表单填写界面。采用固定标题栏、独立滚动字段区、固定底部操作栏；保留规范中的字体、字号、字重、抗锯齿、间距、阴影及焦点态。字段和校验按本任务要求配置，不自动套用 MySQL 业务规则。复用已有组件库，说明未实现的服务能力。交付前核对默认态、聚焦态、错误态和窄屏表现。

字段清单使用以下结构；没有业务要求的限制不要自行添加：

| 字段 | 控件 | 必填 | 默认值 | 占位符 | 校验与依赖 |
| --- | --- | --- | --- | --- | --- |
| 资源名称 | 单行文本 | 是 | 空 | 输入资源名称 | 提交时检查非空 |
| 描述 | 多行文本 | 否 | 空 | 按业务填写 | 无额外长度限制 |

## 页面结构

| 区域 | 设计规则 |
| --- | --- |
| 页面容器 | 位于工作区详情面板内，宽高填满可用空间，纵向 flex；不改成居中弹窗 |
| 标题栏 | 高 63px，内边距 12px 16px，底部 1px 边线；返回、类型图标、标题依次排列，间距 8px |
| 返回 | 32 × 32px 点击区域，图标 16px，圆角 8px；提供可访问名称 |
| 类型图标 | 20 × 20px；存在明确品牌时使用对应资源，不用通用图标代替 |
| 标题与类型 | 两行，类型距标题 2px；没有真实类型信息时不添加说明性副标题 |
| 字段滚动区 | `flex: 1; min-height: 0; overflow: auto`，内边距上 20px、左右及下 24px |
| 分组标题 | 位于卡片外，距卡片 8px |
| 表单卡片 | 靠左排列，宽度 100%、最大 576px，内边距 16px，组间距 16px，圆角 10px |
| 底部操作栏 | 高 65px，内边距 16px 24px，顶部 1px 边线；取消在左、主操作在右；不随字段滚动 |

不为每个字段再套一层卡片。卡片默认高度由字段数量决定；MySQL 默认态约 508px，不作为所有表单的固定高度。

## 字体与颜色

字体栈为 `-apple-system, "system-ui", "PingFang SC", "Segoe UI", sans-serif`。表单根节点设置 `-webkit-font-smoothing: antialiased`，输入和按钮继承字体。不要用降低字重的方式补偿抗锯齿差异。

| 用途 | 字号 / 行高 | 字重 | 颜色 |
| --- | --- | --- | --- |
| 页面标题 | 13px / 20px | 600 | `#09090b` |
| 类型文字 | 12px / 16px | 400 | `#71717a` |
| 分组标题 | 12px / 16px | 500 | `#71717a` |
| 字段标签 | 12px / 16px | 500 | `#09090b` |
| 输入值、协议文字 | 13px / 20px | 400 | `#09090b` |
| 输入占位符 | 13px / 20px | 400 | `#71717a`，opacity 1 |
| 按钮文字 | 13px / 20px | 500 | 按按钮类型 |
| 管理员闭合占位符 | 12px / 16px | 400 | `#71717a` |
| 权限说明 | 11px / 16px | 400 | `#71717a` |
| 错误提示 | 12px / 16px | 400 | `#dc2626` |

| 表面 | 值 |
| --- | --- |
| 页面、标题栏 | `#fff` |
| 卡片 | `oklab(0.967429 0.000417918 -0.00125271 / 0.5)` |

## 字段布局与控件

| 控件 / 组合 | 规格 |
| --- | --- |
| 标签与控件 | 标签在上，控件在下，间距 4px；必填星号紧跟标签，红色，控件同时具备 required 语义 |
| 单行输入 | 高 32px，左右 padding 12px，圆角 8px，透明背景、边线及轻阴影 |
| 多行输入 | 默认高 78px，padding 8px 12px，禁止拖动改变高度；长内容内部滚动 |
| 宽字段 + 短字段 | 三等列、间距 12px，宽字段跨两列；用于地址与端口等有明确长短差异的组合 |
| 两个同级字段 | 两等列、间距 12px；单独半宽字段为 `calc(50% - 6px)` |
| 输入 + 辅助动作 | 同行间距 8px，输入可收缩，按钮不收缩；动作必须与该字段直接相关 |
| 单选组 | 原生 radio 语义，圆圈 16px、描边 2px、选中内点 8px；文字距圆圈 6px，选项间距 20px |
| 次要动作 | 高 32px，圆角 8px，左右 padding 10px；图标 16px，与文字间距 8px |
| 底栏按钮 | 高 32px，左右 padding 12px，圆角 8px；主操作深色，取消使用透明背景 |

长文本不得把栅格撑宽：列使用 `minmax(0, 1fr)`，字段和输入允许收缩。不要为了视觉对齐改变字段语义或顺序。

## 搜索多选

闭合态为按钮，点击后在弹层中输入搜索；不要把闭合按钮改成始终可编辑的输入框。管理员选择器高至少 32px、最多 84px，padding 4px 10px，白底、8px 圆角。

- 使用组件库提供焦点管理、列表键盘导航、选中状态及 Escape 关闭能力。
- 仅显示一个 14px ChevronDown，颜色 `#71717a`，与文字视觉居中；右间距 10px，与左侧文字 padding 一致。
- 文本在箭头前截断，箭头不受文字长度挤压；展开旋转 180°，140ms ease-out，并尊重减少动态效果设置。
- 候选来自调用方数据；不要注入虚构用户。空结果、选中值和清空操作需明确区分。
- 多选、粘贴多个 ID 和移除行为属于当前模板能力，接入其他实体时按业务决定是否保留。

## 状态和交互

| 状态 / 操作 | 规则 |
| --- | --- |
| 默认 | 标签始终可见，placeholder 不替代标签；占位符使用正常字重 |
| 聚焦 | 输入保留蓝色边线和 3px 焦点环，不因全局样式覆盖而丢失键盘焦点提示 |
| 校验失败 | 提示放在卡片末尾，14px 警告图标、文字间距 6px，使用 `role="alert"`；不弹出浏览器原生校验气泡 |
| 编辑错误字段 | 当前 MySQL 模板保留错误，下一次校验更新；其他业务可指定不同策略，需明确记录 |
| 辅助测试 | 校验参数后调用真实服务；没有服务时明确说明本地预览，不能显示虚假的连接成功 |
| 提交 | 使用 form submit 语义；校验顺序由业务定义，不凭界面自行增加端口范围、长度或格式限制 |
| 取消 / 返回 | 当前模板返回类型选择页，不创建记录；未保存提醒由业务需求决定 |
| 异步请求 | 当前模板未提供真实请求态；接入时补充进行中反馈和重复提交防护，不改动按钮占位尺寸 |

MySQL 专用字段、默认值和校验顺序见 [connection-form.md](connection-form.md)，不作为其他配置表单的通用业务规范。密码字段使用 password 控件，不能进入列表摘要、日志或本地持久化示例。

## 窄屏与验收

窄屏是模板适配规则，不代表原站移动端实测结论。优先根据详情面板宽度调整：不够容纳双列时改成单列；保留字段顺序和全部操作，确保底栏可见、卡片无横向溢出。具体容器断点以模板 CSS 为准。

| 验收项 | 通过条件 |
| --- | --- |
| 字体 | 核对字体栈、字号、字重、行高、颜色和抗锯齿；单独检查 `::placeholder` |
| 布局 | 标题栏、底栏、卡片宽度、padding、字段间距与标签间距符合规格 |
| 状态 | 默认、聚焦、错误及多选展开态均可操作，无重复箭头或文字遮挡 |
| 键盘 | 标签关联正确；Tab 顺序自然；radio、下拉、提交与取消可用 |
| 窄屏 | 无横向溢出，长值可截断，底部操作不被滚动内容遮挡 |
| 业务 | 不生成虚假成功状态，不擅自添加校验限制或保存敏感字段 |

复刻 MySQL 表单时运行 [form-fidelity.mjs](../scripts/form-fidelity.mjs)（已集成到 [verify.mjs](../scripts/verify.mjs)），核对 [采集基准](specs/connection-form.json) 和浏览器截图。改为其他业务字段后保留适用样式断言，更新目标选择器；不能直接把 MySQL 的尺寸报告当作新表单的验收结果。

本规范为忠实复刻保留 11px 权限说明、1px 边线、radio 2px 描边、原页圆角组合和阴影；这些是对通用字号下限、单一描边与同心圆角规则的明确例外，不应自动推广到其他设计体系。
