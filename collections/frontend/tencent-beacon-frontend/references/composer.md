# 对话区与输入

主模板：`templates/BeaconComposer.tsx`。父组件负责 `value` / `onChange`，`onSend` 接收 `Prompt`。建议按钮只填入文本，不自动调用模型。

| 部位 | 规格 |
| --- | --- |
| 编辑区域 | 默认高 84px，内边距 `14px 16px 8px`，13px / 24px |
| 工具栏 | 高 46px，内边距 `6px 11px 10px 12px` |
| 外框 | 模板圆角 16px，边线一个变量；内层圆角扣除边线宽度 |
| 发送 | 32px 圆形按钮，空内容禁用，输入非空时深色 |
| 工具按钮 | 高 28px，12px 字号，Lucide 图标与单个 14px chevron |
| 模型名 | 单行、可截断，箭头不受内容长度影响 |
| 建议 | 单行横向滚动；窄屏保留全部建议，不撑宽页面 |

Enter 发送，Shift+Enter 换行；中文输入法组合输入期间 Enter 不发送。使用固定高度的原生 textarea，不实现自动增高或富文本解析。此行为是轻量预览替代方案，原页使用富文本输入并支持拖动高度。

模型名称来自采集时页面显示值，只作为选择器标签，不表示模型可用性、价格、规格或服务承诺。风格预览简化为菜单，不复刻完整的风格图库。技能与模式选项是本地交互夹具，不作为原站选项全集。

附件选择及粘贴仅保存文件名并允许移除，不读取文件内容、不上传。`Prompt.attachments` 因而是名称数组；连接真实应用时应另外定义上传、引用和错误处理接口。输入中的 `@` 与 `/` 为普通文字，未实现原站引用补全。

## 原页文字样式校准

2026-10-30 实测并复核：[样式基准](specs/chat-typography.json)、[91 项比对结果](chat-typography.json)、[预览](../gallery/chat-preview.png)。修改后使用 `scripts/chat-typography.mjs` 的 `compareChat` 核对，完整浏览器检查已集成此步骤。

| 文字 | 字号 / 行高 | 字重 |
| --- | --- | --- |
| 新对话 | 14px / 20px | 500 |
| 主标题 | 20px / 28px | 600 |
| 描述、输入与占位符 | 13px / 24px | 400 |
| 技能、模式、风格、模型 | 12px / 16px | 400 |
| 添加数据、建议、页脚 | 11px / 16px | 400 |

正文使用原页系统字体栈及 `-webkit-font-smoothing: antialiased`。标题使用 Noto Sans SC Variable，品牌名使用 Chiron GoRound Brand；字体片段和 CSS 随模板保留。保留原页标题 -0.02em 字距、11px 文字、页脚中点，作为忠实复刻对通用排版约定的明确例外。标题当前仍固定“数据处理”，未恢复轮换动画；富文本及布局差异仍以上述边界为准。
