`BeaconDataWorkspace` 包含列表、详情与本地状态；`data.ts` 保存无服务依赖的类型、组合筛选函数和虚构数据夹具。查询按名称不区分大小写，来源与名称同时生效。标签页支持方向键、Home / End 和可见焦点。

## 本地演示补充

空数据集是实测页面。新建表单、三行示例表格与删除行为用于验证状态转换，是模板补充，不是原站数据接入流程的逐步复刻。取消或 Escape 不创建数据；创建后恢复“全部”来源及空搜索，并选中刚创建的数据集。重新加载页面后清空。

数据连接包含 MySQL 新建表单、列表和本地摘要，名称与来源组合筛选同样生效。表单规范见 [connection-form.md](connection-form.md)；不会建立真实连接。其他工作区创建类型保留入口和边界说明。完整交互范围见 [interactions.md](interactions.md)。
