## 收录约定

- 每个 Skill 直接放在 `<skill-name>/`，保留 `SKILL.md` 与配套参考文件。
- 每个目录维护 `README.md` 和 `upstream.json`，记录上游仓库、原始路径、commit、文件清单及外部依赖。
- 有明确许可证时保留原文件；未找到时如实记录并附 `NOTICE.md`，不猜测授权。
- README 是使用入口；收录状态、依赖准备与运行验证状态必须分开说明。
