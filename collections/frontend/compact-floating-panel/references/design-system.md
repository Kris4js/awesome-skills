# 通用紧凑浮窗设计规范

## 来源与适用范围

依据当前 `jd-detail-extension/extension/style.css`、`floating.css`、`floating.js` 的实际叠加效果提取（0.8.1）。这是独立样式快照，不要求使用者安装或读取原插件。

窗口、列表、分段选择、折叠区、表格、图片缩略图、统计卡、状态点、悬浮球来自现有实现。**原生 select 下拉框、真正内容 tabs、图片网格及暗色橙色标签是通用补充**，沿用原系统尺寸与配色，不声称源插件已有这些组件。

## 窗口与结构

| 部分 | 默认规格 |
|---|---|
| 窗口 | 400px宽、80vh高；最大不超过视口减16px |
| 初始位置 | 右20px、上10vh；窄屏右边距缩到8px |
| 外观 | 1px细边框、12px圆角、`0 8px 28px #172a3733`阴影 |
| 层级 | 挂载宿主z-index 2147483647，宿主不占布局、不盖透明遮罩 |
| 标题栏 | 内边距12px 14px，底边框；固定不滚动 |
| 内容区 | 内边距14px，`flex:1;min-height:0;overflow:auto` |
| 底栏 | 内边距11px 14px，顶边框；flex布局，按钮42px高 |
| 悬浮球 | 58×58px，右20px/下28px，圆形、14px文字、绿色背景 |

结构：宿主 → ShadowRoot → `.fp` → `.fp-panel`（header/body/footer）与同级 `.fp-ball`。只让内容区滚动；底栏不是相对网页的 fixed。正常交互无遮罩、非模态、点击网页不自动关闭。无需锁住宿主页面滚动。

## 字体与密度

字体栈：`system-ui, -apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`。中文沿用系统无衬线，不加载远程字体。字号单位px；保留浏览器缩放能力。

| 用途 | 字号/字重/行高 |
|---|---|
| 基础 | 13px / 400 / 1.5 |
| 窗口标题 | 16px / 700 |
| 分区标题 | 13px / 650 |
| 列表主标题、按钮、分段项、输入 | 12px / 550–600（输入400） |
| 正文、参数表、普通列表、标签、状态 | 11px / 400 / 1.6 |
| 元信息、数量徽标 | 10px |
| 图片密集表格 | 10px（可读性优先可提高至11px） |
| 统计数字 | 24px / 650 / 1.2；等宽数字 |

11px是当前桌面工具的紧凑基准，不是所有人群的无障碍保证。触屏/阅读密集场景应提供舒适密度（正文至少13px、触控目标至少44px），避免缩小关键文本来解决溢出。

## 颜色

CSS的 `.fp` 是token入口，所有组件引用变量。主视觉为浅灰绿背景、白卡片、深绿主动作；深色使用相同语义token。默认值见 `assets/panel.css`。

状态圆点8px：成功绿、运行蓝、部分成功黄、失败红、未开始灰；旁边必须显示文字。主题深浅变化仍保持状态可读，不仅依赖颜色传递信息。

## 组件

| 组件 | 结构与样式 | 行为 |
|---|---|---|
| 列表 | `.fp-list` 6px间距；`.fp-list-item` 最小52px高、9px 10px内边距、8px圆角 | 主标题12px单行省略，副标题10px；普通正文列表11px。仅待选队列使用176px最大高度，普通列表不强制截断 |
| 输入 | `.fp-field` 标签11px、5px间距；input 7px 9px内边距、7px圆角 | 显式label，placeholder不替代label；范围字段两列，数量/长文本可占整行 |
| 下拉框（补充） | 原生select继承input规格，最小34px高，保留原生箭头 | 优先原生键盘行为；选项过长不撑宽窗口；自定义下拉需额外实现焦点与关闭规则 |
| 分段选择 | `.fp-segmented` 背景浅绿、3px内边距/间隔、9px圆角；选中项白底6px圆角 | 同组radio＋label；仅选择模式，不冒充内容tabs；如有“全部”放最左 |
| 内容tabs（补充） | `.fp-tabs` 同分段视觉，active白底绿字 | role=tablist/tab/tabpanel，aria-selected/controls；方向键切换、活动tab可聚焦，非活动panel hidden |
| 折叠组 | `.fp-group` 9px圆角、1px边框；summary 11px 12px内边距 | 原生details/summary；标题、数量徽标、右侧状态；是否默认展开由内容重要性决定 |
| 数量徽标 | `.fp-count` 最小20px宽、19px高、5px圆角、10px字 | 与正文数字区分，不替代总量说明 |
| 标签 | `.fp-tags` flex wrap，7px间距；单项5px 7px内边距、4px圆角、11px字 | 每项独立DOM节点；静态标签span，筛选标签button＋aria-pressed。过长单项允许折行，禁止整组拼成一条字符串 |
| 统计卡 | 四列、7px间距、9px圆角；数字24px | 窄屏≤360px改两列；“总量”“已取得”含义分开 |
| 参数表 | `.fp-kv`两列，约1:2，11px、8px单元格内边距 | 名称浅底、值左对齐顶对齐；允许长值折行，避免横向溢出 |
| 数据表 | `.fp-table-wrap`最大340px高、内部滚动；table固定布局、10px | 列宽按数据确定，不固定复制业务列；单元格8px 5px，标题浅底 |
| 图片 | `.fp-thumb`44×60px、contain、4px圆角、浅底 | alt明确、懒加载；点击原图使用链接或真实查看器，不裁掉长图内容 |
| 图片网格（补充） | `.fp-gallery`两列、8px间距，预览最大180px高contain | 原图查看单独实现；失败时保留说明，避免破图撑坏布局 |
| 分页 | 两侧上一页/下一页，中间页码，11px | 边界按钮disabled；翻页不隐式改变采集/后台任务 |
| 底栏 | 一主多次；`.fp-primary`绿底白字，其余中性 | 多按钮时主按钮独占一行；按钮可换行但不能挤压内容区至不可用 |
| 空状态/错误 | 11px、虚线边框空态；错误保留明确原因 | 加载中锁定冲突操作；失败可部分保留数据；真实可用才启用重试 |

## 交互契约

- 使用Pointer Events，标题栏 `touch-action:none`、`user-select:none`；拖动起点忽略button/input/select/a等控件。pointer capture在抬起/取消时释放。
- 初始右对齐，拖动后转换为left/top；坐标约束在距视口8px以内的安全区。窗口resize后重新约束，隐藏时先显示再测量尺寸。
- 标题栏可聚焦，方向键每次移动20px，仅在焦点属于标题栏时处理；按钮键盘动作保持默认。
- 收起只设hidden，显示悬浮球并将焦点转移到球。恢复隐藏球，保留输入、结果与列表页码；恢复焦点至标题栏或收起按钮。
- 球和窗口互斥显示；示例中的球固定右下角，不宣称球本身支持拖动或持久记忆位置。
- 多实例使用唯一宿主标识；重复调用返回已有实例。提供destroy，清理resize监听、pointer监听、定时器、Blob URL。
- 浏览器扩展动态import时声明模块依赖和样式资源；避免在MAIN world渲染特权UI。不要把扩展权限API暴露为任意代码执行桥。
- Shadow DOM样式使用 `.fp` token，不把 `:root` 全局规则原样注入宿主。宿主应挂在documentElement下，避免被祖先transform裁切；fullscreen/top-layer场景需另测。

## 验收清单

- [ ] 所有选择器作用域正确，宿主页面的button/h1样式不污染Shadow DOM。
- [ ] 长标题省略、长正文折行；滚动内容不遮挡底栏。
- [ ] 收起恢复保留状态，点击网页不收起，重复挂载无重复窗口。
- [ ] 拖动边界、窗口缩小、375px窄屏均不越界。
- [ ] Tab焦点可见，radio/select/details可键盘操作；状态包含文字。
- [ ] 空、加载、部分成功、错误与禁用状态有真实语义。
- [ ] 暗色不出现白底黑字冲突；reduced-motion关闭非必要动画。
