# Compact Floating Panel · 紧凑工具浮窗

Kris4js 个人维护的前端 Skill，用于搭建或重构网页内紧凑悬浮工具窗口。默认采用 Shadow DOM 隔离，提供浅绿中性色、固定头尾、独立滚动内容和可复用组件样式。

## 适用范围

- 网页内可拖动窗口、收起与悬浮球恢复的实现任务。
- 列表、分段选项、表格、表单、图片和状态展示的统一样式。
- 普通网页或浏览器扩展中的浮窗；不是浏览器原生 sidePanel，也不是独立浏览器窗口。

这是**实现规范与样式资产**，不是开箱即用的插件。拖动控制器、键盘移动、收起恢复、生命周期清理和真实业务逻辑需要在目标项目中实现。无需依赖原插件，也不要求新增 UI 框架。

- 从维护者提供的 `~/tmp/skills/compact-floating-panel/` 原样收录四个源文件，排除 `.DS_Store`。
- 未提供独立 Git 上游或 commit；来源记录使用 `source_type: local` 和逐文件 SHA-256 固定本次内容，不编造版本号。
