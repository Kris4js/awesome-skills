# 标签页

按层级和密度选用。数值来自 `specs/product-tabs.json`、`specs/line-tabs.json`、`specs/switch-tabs.json`（`scripts/capture.sh` 从参考站点重新读取）。弹窗中的白色投影分段样式另见 [selection-dialog.md](selection-dialog.md)。

| 类型 | 用在哪 | 模板 |
|---|---|---|
| 产品标签页 | 页面或大卡片最顶部，切换产品线 / 大板块，标签可带图标 | `templates/ProductTabs.tsx` |
| 默认标签页 | 卡片内部、内容区上方，切换同一板块的视图 | `templates/LineTabs.tsx` |
| 连体切换 Tab | 筛选栏内切换互斥的数据来源或归属范围 | `templates/SwitchTabs.tsx` |

## 产品标签页

![产品标签页](shots/product-tabs.png)

一条浅色底栏，选中的标签是白色、上圆角的「卡片」，与下方白色内容区连成一体。

| 部位 | 规格 |
|---|---|
| 底栏 | 背景 `#F2F5FD`，圆角 `16px 16px 0 0`，高 41px，撑满所在卡片 |
| 标签 | 高 42px（比底栏多 1px，压住内容区上沿），内边距 `8px 16px`，标签间无间距，1px 透明描边 |
| 文字 | 16px / 24px |
| 图标 | 可选，20×20，在文字左侧，间距 4px |
| 未选中 | `#62656C`、400、背景透明；图标用灰色版本 |
| 选中 | `#31343B`、500、背景 `#FFFFFF`，圆角 `16px 16px 0 0`，上/左/右 1px 白色描边；图标用彩色版本 |
| 分隔线 | 相邻两个未选中标签之间 1×14px `#DEE0E3` 竖线；选中标签两侧不显示 |
| 悬停 | 不变色，只有手型光标 |
| 内容区 | 紧接底栏，白色背景 |

## 默认标签页

![默认标签页](shots/line-tabs.png)

纯文字，无底色、无整条底线；选中项下方一条与标签等宽的 2px 指示条。

| 部位 | 规格 |
|---|---|
| 标签 | 高 30px，内边距 `4px 0`，标签之间 24px（`margin-right`） |
| 文字 | 14px / 22px |
| 未选中 | `#62656C`、400 |
| 选中 | `#31343B`、500（文字不变蓝） |
| 指示条 | 高 2px、宽度等于选中标签、贴底、无圆角，`#0057FF`；切换时平移 `transform 0.1s ease-in-out` |
| 整条底线 | 不画 |
| 悬停 | 不变色，只有手型光标 |
| 计数 | 文字后 12px `#93969D`，400 |

## 连体切换 Tab

![组织素材](shots/switch-tabs.png)
![共享素材](shots/switch-tabs-shared.png)

来源为创意组件素材页。选中项白底、蓝色文字及 1px 蓝描边，未选项灰底，各项首尾相接；中间没有轨道内边距或白卡投影。

| 部位 | 规格 |
|---|---|
| 外层 | 实测高 40px，顶部对齐的按钮高 32px；外层圆角 4px，仅作布局容器 |
| 标签 | 14px / 22px、400，内边距 `5px 16px`；宽随文字，不强制等宽 |
| 默认 | `#f2f4f7` 背景，`#31343b` 文字 |
| 选中 | 白底，`#0057ff` 文字；伪元素绘制 1px `#0057ff` 边框，避免宽高跳动 |
| 首尾 | 第一项左圆角 8px，最后一项右圆角 8px；中间项直角；相邻项重叠 1px，选中项在上层 |
| 窄屏 | 仅 Tab 自身可横向滚动，保持单行完整标签，不撑宽页面 |
| 状态 | 禁用项不可操作并降低透明度；键盘焦点有蓝色可见轮廓 |

`SwitchTabs` 接收 `value`、`onChange`、`items`、可访问名称 `label` 和可选 `className`；`items` 使用稳定字符串 value，可带 `disabled`。Base UI Tabs 管理焦点：左右方向键移动焦点，Enter / Space 确认，Home / End 到首尾。切换后的数据加载、路由和分页由调用方处理；关联实际内容面板时使用相同 Base UI Root 下的 `Tabs.Panel`。

原站切换会改变路由并重置三个筛选；独立预览使用两组虚构素材，切换立即重置筛选并更新结果。重置策略属于页面契约，模板不自行清空调用方状态。原站截图和样式分别为 `switch-tabs` / `switch-tabs-shared`，验证读取选中、未选中和伪元素描边；不比较字体导致的文字宽度。模板灰底 hover 是与筛选栏一致的补充状态，尚未作为原站独立采样基准。

## 通用

- `role="tablist"` / `role="tab"` / `aria-selected`；键盘聚焦显示 `focus-visible` 轮廓。
- 标签过多时横向滚动，不换行、不截断。

复用目标项目的标签页组件时，按所选类型核对高度、间距、文字颜色与指示条，保留已有的路由、数据加载和状态管理行为。
